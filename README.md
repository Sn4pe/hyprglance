# hyprglance

A Mac-style window switcher and overview for Hyprland, built on Quickshell.

Hold `Super` and tap `Tab` to walk through your windows with live previews, then release `Super` to switch. Click a preview to jump straight to it, even while `Super` is held.

Press `F3` for an overview of your monitors. Windows travel from their place on screen into a smaller copy of your desktop, with miniatures of your workspaces along the top.

## Requirements

- Hyprland 0.56 or newer with a Lua config (`hyprland.lua`)
- Quickshell 0.3 or newer

The classic `hyprland.conf` is not supported yet: hyprglance relies on the Lua key event API to detect when `Super` is released.

## Install

### Nix with Home Manager

Add the input to your `flake.nix`:

```nix
inputs.hyprglance = {
  url = "github:Sn4pe/hyprglance";
  inputs.nixpkgs.follows = "nixpkgs";
};
```

Enable the module in your Home Manager configuration:

```nix
{ inputs, ... }:
{
  imports = [ inputs.hyprglance.homeManagerModules.default ];

  programs.hyprglance.enable = true;
}
```

Load the keybindings from your Hyprland Lua config:

```lua
dofile(os.getenv("HOME") .. "/.nix-profile/share/hyprglance/hyprglance.lua").setup()
```

If your `hyprland.lua` is generated by Nix, use `config.programs.hyprglance.luaModule` for the path instead.

The module starts hyprglance as a systemd user service on `graphical-session.target`, so Hyprland has to be started through UWSM or with `wayland.windowManager.hyprland.systemd.enable`. Otherwise, start hyprglance as in the manual setup.

### Nix without Home Manager

```sh
nix profile add github:Sn4pe/hyprglance
```

Then follow the manual setup with `hyprglance` as the command and the Lua module from `~/.nix-profile/share/hyprglance/`.

### Manual

Install Quickshell, clone this repository and start it with your session:

```lua
hl.on("hyprland.start", function()
  hl.dispatch(hl.dsp.exec_cmd("qs -p ~/src/hyprglance"))
end)
dofile(os.getenv("HOME") .. "/src/hyprglance/hyprglance.lua").setup()
```

## Usage

### Switcher

- `Super + Tab` / `Super + Shift + Tab`: open, then move forward or back. Hold `Tab` to keep moving
- `Super` + the key left of `1`, with `Shift` to go back: the same, only with windows of the current app. Does nothing if the app has one window
- Release `Super`: switch to the selected window
- Click: switch to that window
- Middle click or `Super + Q`: close the window
- `Escape`: close without switching

### Overview

- `F3`: open or close
- Click a window or a workspace to go there, or anywhere else to close
- Drag a window onto a workspace or another monitor to move it there. Empty workspaces appear while you drag
- Number keys: go to a workspace
- `Left` / `Right`, then `Enter`: pick a workspace
- `Tab` / `Shift + Tab`, then `Enter`: pick a window
- Middle click or `Q`: close the window
